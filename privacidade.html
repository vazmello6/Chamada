Política de privacidade do Chamada

Atualizada em 23/10/2026.

O Chamada é um programa de uso pessoal que roda no computador do próprio professor. Não existe servidor do Chamada: nada é enviado ao autor do programa nem a terceiros.

O que o programa acessa no Google

  • Google Drive, só os arquivos criados pelo próprio programa (permissão https://www.googleapis.com/auth/drive.file). O programa não vê, não lê e não altera nenhum outro arquivo do Drive.
  • O e-mail da conta Google, só para conferir se a conta autorizada é a que o professor digitou.

Para que usa

Para manter uma pasta do programa (as chamadas e o próprio programa) igual nos computadores do professor e guardar cópias de segurança no Drive dele.

Onde ficam os dados

Os dados ficam só nos computadores do professor e na pasta do Google Drive dele. A autorização do Google fica guardada no computador, criptografada pelo Windows. Os dados não são vendidos, compartilhados, usados para publicidade nem para treinar modelos de inteligência artificial.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

A qualquer momento, em myaccount.google.com/permissions → Chamada → Remover acesso. Os arquivos que o programa criou no Drive continuam lá até o professor apagá-los.
